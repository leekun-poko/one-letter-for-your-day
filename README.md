A tiny Python program that writes exactly one letter — D — to `entry.txt`, with no trailing newline, so the file is exactly one byte. D for deadline: the one letter that shapes the whole day. The output directory comes from `$MAKEFUN_OUTPUT_DIR` and defaults to `/output`. Python 3.13, standard library only.

## Run it

```sh
python3 main.py
```
